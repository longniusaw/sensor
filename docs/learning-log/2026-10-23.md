## 三、技术知识点

### Git 基础

- git init：初始化本地仓库
- git add：将文件加入暂存区
- git commit：保存本地版本
- git push：将本地提交推送到远程仓库
- git pull：获取并整合远程更新
- .gitignore：配置不需要纳入版本管理的文件

### ROS 2 项目管理

- 工作空间根目录作为 Git 仓库根目录
- 源代码纳入版本管理
- 编译产物和日志不上传

## 四、遇到的问题及解决方法

### 问题 1：GitHub 不支持账户密码推送

原因：
GitHub 不支持使用账户密码进行 Git HTTPS 操作。

解决：
使用 GitHub CLI 完成身份验证。

### 问题 2：本地与远程仓库历史不一致

原因：
本地和 GitHub 分别创建了初始提交。

解决：
使用 --allow-unrelated-histories 合并两边的历史，
随后成功推送。
